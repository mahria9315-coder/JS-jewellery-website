# ویب سائٹ لائیو گائیڈ (Website Live Guide - Urdu)

یہ گائیڈ بتاتی ہے کہ ویب سائٹ کو لائیو/پروڈکشن میں لے جانے کے لیے کیا ضروری ہے۔ یہ گائیڈ بذات خود لائیو ہونے کی تصدیق نہیں کرتی۔

## 1) موجودہ حقیقت (Reality)
- پروجیکٹ مقامی طور پر تیار/تصدیق شدہ حصوں کے ساتھ موجود ہے، مگر پروڈکشن لائیو کے لیے کلائنٹ/مالک کی طرف سے کئی ضروری اقدامات باقی ہوتے ہیں۔
- `docs/PRODUCTION_READINESS.md` اور `docs/FINAL_LOCAL_COMPLETION_REPORT.md` کے مطابق مکمل production readiness کا درجہ **NO-GO / blocked by client actions** ہے جب تک مطلوبہ پیشگی شرائط پوری نہ ہوں۔

## 2) لائیو سے پہلے تکنیکی پیشگی شرائط (Environment & Build)
سرور/پروڈکشن ماحول میں (ناموں کی سطح پر):
- درست `DATABASE_URL`، `NEXT_PUBLIC_SITE_URL` (پروڈکشن میں https اور localhost نہیں)، secrets جیسے `CHECKOUT_DRAFT_SECRET`, `ADMIN_MFA_ENCRYPTION_KEY`, `BLOB_READ_WRITE_TOKEN` وغیرہ کنفیگر ہوں۔
- ریٹ لمیٹنگ پروڈکشن کے مطابق (مثلاً `RATE_LIMIT_PROVIDER=upstash` اور متعلقہ Upstash env) کنفیگر ہو۔
- env چیک: `npm run env:check` (پروڈکشن موڈ) — تمام required اقدار درست ہونی چاہئیں۔
- بلڈ/اسٹارٹ کمانڈز (انگریزی): `npm run build`, `npm run start` (ہوسٹنگ پلیٹ فارم کے مطابق)۔
- Prisma/migrations پلان حسبِ دستاویز (پروڈکشن میں محتاطی سے، بغیر غیر مجاز تبدیلی)۔

## 3) ڈیٹا بیس، بیک اپ، اور بحالی
- پروڈکشن ڈیٹا بیس تیار اور محفوظ ہو۔
- بیک اپ شیڈول، آف سائٹ انکرپٹڈ اسٹوریج، اور کم از کم ایک ریسٹور مشق مکمل ہو (`BACKUP_RECOVERY_GUIDE_URDU.md`).
- ہوسٹنگ بیک اپ/PITR (اگر ہو) کی تصدیق اور دستاویز سازی کلائنٹ کرے۔

## 4) کاروباری اور آپریشنل تیاری
- اصلی سپلائرز، معاہدے، تصویر حقوق، قیمت/اسٹاک تصدیق شدہ ہوں۔
- ادائیگی اکاؤنٹس (Bank/Easypaisa) درست اور سرور پر کنفیگر ہوں؛ ادائیگی تصدیق کا عمل طے ہو۔
- کورئیر کمپنیوں کی شرائط/زیورات قبولیت اور منزلیں تصدیق شدہ ہوں؛ بغیر تصدیق کچھ بھی "approved" نہ مانیں۔
- پالیسی/مواد/رابطہ معلومات درست ہوں۔
- COD غیر فعال رہے (approved scope کے مطابق)۔

## 5) سیکیورٹی اور رسائی
- پہلا Super Admin محفوظ طریقے سے بنایا گیا ہو؛ `ADMIN_SETUP_SECRET` کے استعمال کے بعد اسے ہٹانے/روٹیٹ کرنے کا پلان ہو۔
- MFA اور مضبوط پاس ورڈ پالیسیاں عمل میں ہوں۔
- ایڈمن رسائی صرف مجاز افراد کو ہو۔

## 6) گو لائیو سے پہلے حتمی جانچ
- `FINAL_LAUNCH_CHECKLIST_URDU.md` کی ہر لازمی شق مکمل کریں۔
- کوئی بھی لازمی شق نامکمل ہو تو لانچ **NO-GO** سمجھیں۔
- Developer اور Client کام الگ الگ نشان زد ہیں؛ کلائنٹ والے تمام آئٹمز پورے ہونے چاہئیں۔

## 7) لائیو کے بعد (اگر لائیو کیا جائے)
- آرڈرز، ادائیگی سبمیشنز، اور ایڈمن تصدیقی کام باقاعدگی سے مانیٹر کریں۔
- بیک اپ کامیابی اور رسائی کی وقتاً فوقتاً جانچ کریں۔
- کسی غیر معمولی مسئلے پر `TROUBLESHOOTING_URDU.md` اور متعلقہ ماڈیول گائیڈ دیکھیں۔

> نوٹ: ہوسٹنگ پلیٹ فارم، DNS، SSL، اور پروڈکشن ڈیپلائمنٹ کے عین کلکس/اسٹیپس فراہم کنندہ کے مطابق مختلف ہو سکتے ہیں؛ اس ریپو میں جو تصدیق شدہ کمانڈز/سیٹنگ نام موجود ہیں وہی استعمال کریں اور غیر موجود تفصیلات ایجاد نہ کریں۔
