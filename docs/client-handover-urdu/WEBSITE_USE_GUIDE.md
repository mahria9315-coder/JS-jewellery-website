# ویب سائٹ استعمال گائیڈ (Website Use Guide - Urdu)

یہ گائیڈ JS Jewellers ویب سائٹ کے عوامی (customer-facing) حصے کو سمجھنے اور استعمال کرنے کے لیے ہے۔

## 1) ویب سائٹ کا مقصد
- JS Jewellers ایک زیورات کی ویب سائٹ ہے (dropshipping ماڈل)۔
- گاہک مصنوعات دیکھ سکتا ہے، کارٹ میں شامل کر سکتا ہے، چیک آؤٹ کر سکتا ہے، اور دستی ادائیگی کی تفصیل سبمٹ کر سکتا ہے۔
- آرڈر، ادائیگی کی تصدیق، سپلائر/کورئیر کارروائیاں ایڈمن ٹیم Admin Panel میں سنبھالتی ہے۔

## 2) اہم عوامی صفحات (Public Pages/Routes)
- **Home (ہوم):** `/` — مرکزی صفحہ۔
- **Collections (کلیکشنز):** `/collections` اور `/collections/[slug]` — کیٹگری/کلیکشن کے مطابق مصنوعات۔
- **Product page (پروڈکٹ صفحہ):** `/products/[slug]` — پروڈکٹ تفصیل، قیمت، دستیابی، تصاویر، اور (اگر دستیاب ہو) customization۔
- **Search (تلاش):** `/search` — مصنوعات تلاش کرنا۔
- **Cart (کارٹ):** `/cart` — منتخب اشیاء، مقدار، خلاصہ، checkout پر جانا۔
- **Checkout (چیک آؤٹ):** `/checkout` — ڈیلیوری تفصیلات اور ادائیگی طریقہ منتخب کرنا۔
- **Checkout review:** `/checkout/review` — آرڈر دینے سے پہلے جائزہ (review) اور تصدیق۔
- **Order lookup (آرڈر تلاش):** `/orders/lookup` — آرڈر نمبر اور checkout ای میل سے اپنا آرڈر کھولنا۔
- **Order page (نجی آرڈر صفحہ):** `/orders/[orderNumber]?token=...` — آرڈر کی تفصیل، ادائیگی ہدایات/سبمیشن، اسٹیٹس، واپسی درخواست (اگر اہل ہو)۔
- **Policies/Info:** `/shipping`, `/returns`, `/privacy`, `/terms` — شپنگ، واپسی، پرائیویسی، شرائط۔

> نجی آرڈر لنک/ٹوکن خفیہ سمجھیں؛ اسے عوامی طور پر شیئر نہ کریں۔

## 3) خریداری کا مکمل عمل (Step-by-step)
### مرحلہ 1: پروڈکٹ دیکھیں
1. ہوم، کلیکشن، یا سرچ سے پروڈکٹ کھولیں۔
2. قیمت (PKR) اور دستیابی/تفصیل پڑھیں۔
3. اگر پروڈکٹ پر customization دستیاب ہو تو منظور شدہ آپشنز کے مطابق تفصیل دیں (سسٹم صرف منظور شدہ font/colour/text قواعد قبول کرتا ہے)۔

### مرحلہ 2: کارٹ میں شامل کریں
1. پروڈکٹ صفحہ سے **Add to cart**/متعلقہ بٹن استعمال کریں (اگر دستیاب ہو)۔
2. `/cart` پر جائیں۔
3. مقدار (Quantity) تبدیل کرنے کے لیے **Update** بٹن، ہٹانے کے لیے **Remove** بٹن استعمال کریں۔
4. کارٹ میں قیمت/دستیابی سرور کی طرف سے دوبارہ چیک ہوتی ہے؛ اگر کوئی مسئلہ ہو تو پیغام نظر آئے گا۔

### مرحلہ 3: Checkout
1. کارٹ سے **Proceed to checkout** پر کلک کریں۔
2. `/checkout` پر ڈیلیوری تفصیلات درج کریں (نام، ای میل، فون، ملک/شہر، پتہ وغیرہ — فارم کے مطابق)۔
3. دستیاب ادائیگی طریقہ منتخب کریں (**Bank Transfer** یا **Easypaisa**، اگر configured ہوں)۔
4. تفصیلات محفوظ کر کے review پر جائیں۔
5. `/checkout/review` پر معلومات چیک کریں، ضروری تصدیق/پالیسی قبولیت (اگر مانگی جائے) کریں، اور آرڈر پلیس کریں۔
6. آرڈر بننے پر نجی آرڈر صفحہ کھل جائے گا اور کارٹ خالی ہو جائے گا۔

نوٹ: ملک/ڈیلیوری اہلیت منظور شدہ کورئیر/سیٹنگز پر منحصر ہے۔ اگر طریقہ یا ڈیلیوری دستیاب نہ ہو تو سسٹم مناسب پیغام دکھائے گا۔

### مرحلہ 4: ادائیگی سبمٹ کریں
1. نجی آرڈر صفحہ پر ادائیگی ہدایات، Total، اور Payment Reference دیکھیں۔
2. اسی اکاؤنٹ میں درست رقم بھیجیں۔
3. اپنا transaction reference (اور اختیاری نوٹ) سبمٹ کریں۔
4. اسٹیٹس `SUBMITTED` ہونے کا مطلب ہے تفصیل موصول ہو گئی؛ رقم کی تصدیق ایڈمن دستی طور پر کرے گا۔

### مرحلہ 5: آرڈر ٹریک/دیکھیں
1. `/orders/lookup` پر جائیں۔
2. آرڈر نمبر اور وہی ای میل درج کریں جو checkout پر استعمال ہوا۔
3. درست معلومات پر سسٹم نجی آرڈر صفحہ دکھائے گا۔
4. آرڈر صفحہ پر Order Status، Payment Status، Production Status، ادائیگی ہسٹری، اور (اگر موجود ہو) کورئیر ٹریکنگ ریفرنس/لنک نظر آ سکتا ہے۔

## 4) آرڈر/ادائیگی/پروڈکشن اسٹیٹس (جو سسٹم میں موجود ہیں)
### Order Status (آرڈر کی حالت)
- `PENDING_CONFIRMATION` — تصدیق کا انتظار
- `CONFIRMED` — تصدیق شدہ
- `FORWARDED` — سپلائر کو بھیجا گیا
- `SUPPLIER_PROCESSING` — سپلائر پراسیسنگ میں
- `SHIPPED` — بھیج دیا گیا
- `DELIVERED` — موصول/ڈیلیور
- `CANCELLED` — منسوخ
- `RETURNED` — واپس

### Payment Status (ادائیگی کی حالت)
- `PENDING`, `SUBMITTED`, `VERIFIED`, `REJECTED`, `REFUNDED` (تفصیل `PAYMENT_GUIDE_URDU.md` میں)

### Production Status (پروڈکشن کی حالت)
- `PENDING`, `CONFIRMED`, `IN_PRODUCTION`, `COMPLETED`

نوٹ: یہ اسٹیٹس الگ الگ ہیں؛ ایک کا بدلنا خود بخود دوسرے کو مکمل نہیں کرتا (مثلاً ادائیگی کی تصدیق الگ عمل ہے)۔

## 5) واپسی (Returns) - گاہک
- آرڈر نجی صفحہ پر واپسی کی اہلیت (eligibility) اور موجودہ درخواست کی حالت دکھائی جا سکتی ہے۔
- اگر اہل ہوں تو گاہک واپسی کی وجہ (reason) اور وضاحت دے کر درخواست سبمٹ کر سکتا ہے۔
- واپسی کی وجوہات (سسٹم میں): Change of mind, Defective/faulty, Damaged in transit, Incorrect item, Other protected issue۔
- واپسی/کٹوتی کے قواعد اور محفوظ کیسز (protected cases) سرور رولز کے مطابق لاگو ہوتے ہیں؛ ایڈمن جائزہ/فیصلہ کرتا ہے۔

## 6) اہم احتیاطی باتیں
- آرڈر/ادائیگی کے بارے میں صرف ویب سائٹ پر دکھائی گئی معلومات اور اصل اکاؤنٹ ریکارڈ پر اعتماد کریں۔
- Admin Panel کا لنک/رسائی صرف مجاز عملے کو دیں۔
- اگر کوئی معلومات غیر یقینی ہو تو اندازہ نہ لگائیں؛ سپلائر/اکاؤنٹ/کورئیر سے تصدیق کریں۔
